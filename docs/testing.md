# 测试策略与现状

没有硬件时能验的都要验：协议、队列、语音管线、资产生成、三端契约。真机行为只能等设备，但要先把"能在这里发现的问题"全挖出来。

## 现在自动跑什么

```bash
npm test          # 49 个主机测试 + 14 个资产/契约测试
npm run test:host # 只跑插件
npm run test:assets
```

| 层 | 覆盖 | 用例数 |
| --- | --- | --- |
| 协议编解码 | NDJSON 分帧、多字节字符跨包、超长行、非法 JSON | 3 |
| 设备服务 | 握手、协议版本、token、未握手超时、二次连接替换（旧连接收 `bye`）、垃圾帧、超长帧、未知类型、乱序 decision | 8 |
| 局域网发现 | 广播应答内容、忽略非 discover、proto 不匹配、重复应答 | 3 |
| 审批视图 | 像素宽度折行、截断（不是拒绝）、真实沙箱 reason、displayReason 优先、空内容回落 | 7 |
| 审批队列 | 串行、超时回落、取消、断线回落、替换手表补发、并发计数 | 7 |
| 语音（主机） | 分片拼接、WAV 头、超过 60s、乱序 seq、重复 start、空文本、未启动就 end、未启用、模型未就绪 | 12 |
| 工具摘要 / 预览缓存 | bash 命令、写文件路径、截断、LRU 上限 | 2 |

## 这轮补的（gap → 做了什么）

| 之前的缺口 | 风险 | 处理 |
| --- | --- | --- |
| UDP 发现 0 测试 | 手表永远找不到主机 | 3 个真实 UDP 用例 |
| 协议健壮性 0 测试 | 一个坏包让服务卡死/崩溃 | 8 个用例；确认违规连接会关闭、服务本身存活 |
| 语音边界 0 测试 | 超长录音撑爆内存、乱序拼错 | 7 个用例；60s 上限、按到达顺序拼接 |
| 资产生成器 0 测试 | 精灵错位、调色板错位只在真机上才看得出 | 8 个用例；当场验证了"共用裁切框"和"索引 0 透明" |
| 三端消息名靠人记 | 改名后一端失联 | 4 个契约用例；**当场抓到 `queue` 消息没写进协议文档，已补** |
| 排版宽度两处硬编码 | 主机按 420 折行、固件按别的宽度画会溢出 | 1 个契约用例锁死 420 |

## 还缺的（以及为什么现在补不了）

| 缺口 | 为什么 | 计划 |
| --- | --- | --- |
| 固件运行时逻辑（按键状态机、录音缓冲、UI 刷新） | 需要 `M5Unified` 桩件才能在本机跑，桩件本身可能偏离真实 API | 到货后按验收清单逐项过；如仍想要，可做"纯逻辑抽离 + 桩件"重构 |
| 真实麦克风链路 | ES8311 增益、I2S 时序只有硬件能给答案 | 到货校准 `magnification`，录音 3 秒看波形/识别率 |
| 按键左右 | 取决于装配方向 | 到货按一下就知道，`STOPWATCH_SWAP_BUTTONS` 一行切换 |
| Live2D 烘焙的观感 | 只能人眼判断 | 已出 466 实机尺寸预览图；到货后对比 |
| 长时间稳定性 | 心跳、断网重连、内存泄漏都要跑小时级 | 用 `tools/fake-device.mjs` 做 24h soak（可以现在就跑，见下） |
| 端到端真机 approval | 需要设备 + 权限确认 | 到货后按验证清单 |

## 现在就能做的 soak（不需要硬件）

```bash
node tools/fake-device.mjs --auto allow --delay 500 &
# 让它连着跑，观察 DSH 日志里的 reconnect / heartbeat 记录
```

`fake-device` 断线重连时，插件会走"设备离线 → 回落 Web UI → 重连补发"的路径，这条链路目前只有短测试覆盖，跑一夜能抓到内存增长和时钟漂移。
