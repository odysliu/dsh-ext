# 角色图放这里

把 PNG 丢进这个目录，命名为下面任意一个即可（**有几张放几张**，缺的状态我用待机图代替）：

| 文件名 | 用在什么时候 |
| --- | --- |
| `idle.png` | 待机（默认必须有一张） |
| `alert.png` | 有确认请求、闪烁提醒时（可选） |
| `happy.png` | 手表上点了「同意」后 |
| `sad.png` | 点了「拒绝」或超时回落 |

## 图片要求（越接近越省事）

- **PNG，透明背景**，正方形，建议 **1024×1024**（≥512 也行）
- 角色**居中**，四周留 ~8% 空白；全身完整，不要裁到鳍/尾巴
- **扁平色块**优先：≤16 种颜色、边缘干净；避免细到 1px 的线、照片质感、大面积渐变
- 背景是深色（#090B16），所以**别用深蓝/藏青**做主体色，会糊在背景里
- 多张表情请保持同一角色、同一画风、同一光照方向

## 我会怎么处理

`python3 tools/build_sprites.py` 会：

1. 去掉残留背景 → 裁到内容边界 → 等比缩放进 300×300 → 居中
2. 量化成 16 色，打包成 4bpp（每像素 4 bit）的 C 数组
3. 生成 `firmware/stopwatch/src/assets/characters.h`，固件直接按帧 blit，不再程序化绘制

所以：**你只要给图，尺寸、调色板、格式、固件接入都由我来兜。**
